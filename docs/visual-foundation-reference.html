Visual foundation exploration

Two app-accent directions on a shared neutral system, plus the official TransMilenio trunk-corridor colors routes will actually render in. Toggle theme and accent below; the corridor colors don't change — they're fixed, real-world reference points, not part of the app's own theme.

On the Manual de Marca Ciudad "Bogotá": reviewed it — bold red/yellow/blue, a rounded display face, built for tourism/investment marketing (Alcaldía Mayor, IDT). Not carrying the palette or logo forward: it reads as an official government product, which conflicts directly with the app's non-affiliation stance and the calm/muted direction already set. What is worth keeping is the underlying idea behind the "Á" mark — Bogotá as the world's highest major city, the plateau/mountain as identity — which lines up naturally with the Páramo accent direction below, without borrowing any of the actual brand assets.

App palette (theme-able)

Neutrals stay fixed across both directions — only the accent hue changes. The accent is reserved for app chrome only: "you are here," selection state, UI controls. It is deliberately kept muted/desaturated so it never reads as a route color — every real route color below is fully saturated, so a soft accent is the visual signal "this is the app talking, not a route."

A second, coarser layer sits above corridor color: TransMilenio (closed, exclusive-lane BRT) vs. SITP zonal (open system, shares regular streets). TM's real fleet is red-liveried; SITP's zonal fleet has traditionally been blue (yellow/green variants mark Euro6/electric engines, not route identity — not used here). Route/bus markers use this as the base body color, with the trunk corridor color layered on top only for TM, since SITP zonal routes have no equivalent official per-route color chart.

Directionality treatment

Same corridor hue for both directions (so the route stays recognizable) — direction is shown by a lightness variation plus an explicit arrowhead, never color alone, so it still reads correctly for colorblind riders and holds up in the "unmistakable at a glance" success criterion from Core Experience.

Map markers

Three marker types, each shaped so the difference between them is legible by silhouette alone, not just color — important given riders will glance at this while walking. Stops are static dots; buses read as a small vehicle body (a rounded capsule with a windshield band near the front, not an abstract arrowhead) that rotates to face its heading; "you are here" stays the single pin already shown above.

Working rules

Four-tier color system

System identity (TM red vs. SITP blue) → corridor color (TM trunk only, vivid, fixed per letter) → app accent (muted, chrome only) → semantic live/unavailable (independent of the rest). Each tier means one thing and is never borrowed for another.

Thin lines, soft corners

2–3px route strokes, 8–22px corner radii depending on element size — Madrid-map restraint, not rounded-for-its-own-sake.

System fonts, on purpose

No custom webfont load — matches the architecture's lean-payload requirement (NFR1). Hierarchy comes from weight, size and spacing, and a monospace face for live times/distances (tabular figures, departure-board feel).

Both themes, same rules

Dark mode isn't an inversion — neutrals shift to a warm near-black and the app accent brightens slightly to hold contrast; route corridor colors stay as-is in both themes since they're a fixed external reference, not part of the app's own palette.

Recommendation

Páramo (the moss-green direction) over Sabana, and — now that real corridor colors are in the mix — for a different reason than hue-uniqueness (every hue is already used by some corridor, A and G are both blue-family, B is already green). The actual separation comes from saturation and value: Páramo is kept deliberately muted/dusty next to any corridor's fully saturated color, so "app UI" and "route identity" stay visually distinct by intensity, not by hue. It also carries the páramo/altitude echo from the city brand review above, without touching the brand's own assets.
